# ダウト将棋 ルール仕様書

v0.1

## 1．ゲームの概要

通常の将棋と同じ40枚の駒を使う、2人用ゲーム。

王と歩を盤上に配置し、残りの駒を共通の山にする。各プレイヤーは手番ごとに1枚ツモり、盤上の駒を動かすか、手札の駒を打つ。

手札の駒を打つときは、正体を隠して別の種類を名乗れる。相手は「ダウト」で嘘を指摘できる。

盤上に確定した駒の動きは公開情報とし、将棋の読み合いを保つ。

## 2．使用物と駒の総数

- 9×9の将棋盤
- 通常の将棋駒40枚
- 山と手札の正体を隠すカバーなど
- 偽装した駒の「盤上での種類」と「成り」を示す表示

駒の構成は以下のとおり。対局中に駒を追加しない。

| 種類     |      枚数 |
| ------ | ------: |
| 王・玉    |    合計2枚 |
| 飛車     |      2枚 |
| 角      |      2枚 |
| 金      |      4枚 |
| 銀      |      4枚 |
| 桂      |      4枚 |
| 香      |      4枚 |
| 歩      |     18枚 |
| **合計** | **40枚** |

通常の駒の裏面には成駒が書かれているため、単に裏返すだけでは秘密の駒として扱わない。外見から種類を識別できないようにする。

## 3．用語

| 用語     | 意味                                |
| ------ | --------------------------------- |
| 山      | 両者が共通で使う、正体と順序を隠した駒の集まり           |
| 手札     | 自分だけが正体を確認できる、手元の駒                |
| 捨て場    | 捨てられた駒や取られた駒を、表向きで置く場所            |
| 本来の種類  | 実際の駒に書かれた種類                       |
| 宣言した種類 | 伏せて打つ際に名乗った種類                     |
| 偽装打ち   | 正体を隠し、種類を宣言して駒を打つこと。本当の種類を宣言してもよい |
| ダウト    | 直前の偽装打ちの宣言が嘘だと指摘すること              |
| スルー    | ダウトせず、宣言した種類として打ちを認めること           |

## 4．対局の準備

### 4.1 初期配置

各プレイヤーの王1枚と歩9枚を、通常の将棋と同じ位置に置く。他の駒は盤上に置かない。

上が後手、下が先手。歩はそれぞれ相手側に向ける。

```text
       ９ ８ ７ ６ ５ ４ ３ ２ １

  一   ・ ・ ・ ・ 玉 ・ ・ ・ ・
  二   ・ ・ ・ ・ ・ ・ ・ ・ ・
  三   歩 歩 歩 歩 歩 歩 歩 歩 歩
  四   ・ ・ ・ ・ ・ ・ ・ ・ ・
  五   ・ ・ ・ ・ ・ ・ ・ ・ ・
  六   ・ ・ ・ ・ ・ ・ ・ ・ ・
  七   歩 歩 歩 歩 歩 歩 歩 歩 歩
  八   ・ ・ ・ ・ ・ ・ ・ ・ ・
  九   ・ ・ ・ ・ 王 ・ ・ ・ ・
```

### 4.2 山と初期手札

1. 盤上に置かなかった20枚を、正体が見えない状態で混ぜ、共通の山にする。
2. 先手・後手を決める。
3. 先手から交互に1枚ずつ引き、両者の手札を3枚にする。
4. 引いた駒は、持ち主だけが確認する。

開始時の内訳は、盤上20枚、両者の手札計6枚、山14枚、捨て場0枚。

## 5．手番の流れ

各手番は、次の順序で処理する。

1. **ツモ：** 山から1枚引き、手札に加える。
2. **行動：** 盤上の駒を1枚動かすか、手札から1枚打つ。
3. **ダウトの解決：** 偽装打ちの場合のみ行う。
4. **王手への対応結果を確認する。**
5. **手札調整：** 手札が3枚を超えていれば、3枚になるまで選んで表向きで捨てる。
6. 相手の手番へ移る。

先手も最初の手番にツモを行う。

手札が3枚未満でも、1回のツモで引くのは1枚だけ。手札を3枚まで一度に補充することはない。

パスはできない。

## 6．盤上の駒の動かし方

駒の動き、駒を取る方法、敵陣の範囲、成りの条件は、原則として通常の将棋に従う。

偽装打ちが成立した駒は、**宣言した種類**で動く。

例：本来は香でも、「銀」として打ちが成立した駒は、銀として動き、銀として成る。

盤上の駒について、以下の情報は常に両者に分かる状態にする。

- 所有者
- 盤上での種類
- 成っているかどうか

偽装した駒の本来の種類は、公開が必要になるまで隠しておく。

## 7．駒を取る

取った駒は、自分の持ち駒にせず、**共通の捨て場に表向きで置く**。

偽装された駒を取った場合は、その正体を公開する。宣言した種類と成りの表示を外し、本来の未成の駒に戻して捨て場に置く。

例：香が銀を名乗り、成銀になっていた場合でも、取られたら香として捨て場に置く。

捨て場から直接駒を打つことはできない。

## 8．手札から駒を打つ

### 8.1 表で打つ

手札の駒を公開し、本来の種類として空きマスに打つ。この打ち方にはダウトできない。

### 8.2 偽装打ち

手札の駒を1枚選び、正体を隠したまま空きマスに置き、種類を宣言する。

宣言できるのは、**飛・角・金・銀・桂・香・歩**の7種類。王や成駒は宣言できない。

本来の種類を正直に宣言しても、異なる種類を宣言してもよい。

相手の回答が確定するまで、次の行動に進まない。

### 8.3 打つ場所の制約

打つ場所の合法性は、宣言した種類で判断する。

- 駒のあるマスには打てない。
- 行き所のない駒は打てない。
- 二歩は禁止。盤上で歩として扱う未成の駒で判定する。
- 成った状態では打てない。

本来の種類が何であっても、この判定は変わらない。

## 9．ダウトとスルー

### 9.1 宣言できるタイミング

ダウトできるのは、相手が偽装打ちをした直後だけ。

次のツモを行う前に、ダウトかスルーを明示する。一度スルーした駒には、後からダウトできない。

手札が0枚のプレイヤーはダウトできず、スルーする。

### 9.2 スルー

打ちは成立する。

本来の種類は公開せず、宣言した種類を表示する。その駒は盤上にいる間、宣言した種類として扱う。

### 9.3 ダウト

打った駒の正体を公開し、本来の種類と宣言を比較する。

| 判定    | 処理                                           |
| ----- | -------------------------------------------- |
| 宣言が嘘  | 打ちを取り消し、その駒を本来の種類で捨て場へ送る。打った側の行動は消費され、指し直せない |
| 宣言が本当 | 打ちは成立。ダウトした側は自分の手札を1枚選び、表向きで捨てる              |

どちらの場合も、次の手番は通常どおり相手へ移る。ダウトによって手番を追加したり、飛ばしたりしない。

## 10．山の再構築

ツモの時点で山が空なら、捨て場の全駒を伏せて十分に混ぜ、新しい山にする。その山から1枚引く。

- 山に駒が残っている間は、捨て場を混ぜ込まない。
- 両者の手札や盤上の駒は、山に戻さない。
- 捨て場の駒は、元の所有者に関係なく共通の山へ戻る。
- 山と捨て場の両方が空なら、その手番のツモを省略する。
- 後に捨て場へ駒が戻れば、次に必要となったツモの時点で山を再構築する。

駒数を40枚に固定するため、局面によってはツモのない手番が発生する。

## 11．王手と勝敗

### 11.1 王手の判定

王手は、盤上で確定している種類と成りの状態に基づいて判定する。

偽装打ちによる王手は、ダウトまたはスルーの解決後に確定する。

### 11.2 王手への対応

王手を受けた側も、通常どおり手番の最初にツモを行う。引いた駒を使って王手を防いでもよい。

その手番の行動とダウトの解決が終わった時点で、自分への王手を解消しなければならない。

王手を防ぐために偽装打ちをし、ダウトで嘘を見破られた結果、王手が残った場合は、その時点で負け。

### 11.3 詰みの扱い

手札が非公開で、次のツモによって受ける手が増えるため、盤面だけで詰みを確定しない。

王手を受けた側は、ツモを行ったうえで受けを試みる。王手を解消できなければ負け。

この試遊版では、処理を統一するため、**通常の将棋の「打ち歩詰め禁止」は適用しない**。二歩と行き所のない駒の禁止は適用する。

### 11.4 その他の勝敗

- 投了したプレイヤーは負け。
- 王手を受けていなくても、ツモ後に合法な行動が一つもなければ負け。
- 王を取るまで指し続ける方式にはしない。
- 双方が合意すれば引き分けにできる。

千日手と持将棋の自動判定は、この試遊版では設けない。

## 12．情報の公開範囲

| 情報                 | 公開範囲             |
| ------------------ | ---------------- |
| 盤上の位置・所有者・有効な種類・成り | 両者に公開            |
| 手札の枚数              | 両者に公開            |
| 手札の正体              | 持ち主だけ            |
| 山の残り枚数             | 両者に公開            |
| 山の順序・中身            | 非公開              |
| 捨て場の駒              | 両者に公開            |
| スルーされた偽装駒の本来の種類    | 打った本人だけ。取られた時に公開 |

捨て場は、山に戻されるまで両者が確認できる。

## 13．処理例

### 例A：盤上の駒を動かす

手札3枚の状態で銀をツモり、4枚になる。

盤上の歩を進めたあと、手札から香を1枚選んで公開し、捨て場に置く。手札は3枚になる。

### 例B：嘘が通る

手札の香を伏せて打ち、「銀」と宣言する。

相手がスルーしたため、以後その駒は銀として動く。後で取られたら、香に戻って捨て場へ送られる。

### 例C：嘘を見破る

相手が歩を「金」と宣言して打つ。

ダウトにより歩だと判明したため、その歩を捨て場へ送る。相手は別の手を指し直せず、行動を終える。

### 例D：本物を疑う

相手が本物の角を伏せて「角」と宣言する。

ダウトしたが本物だったため、角の打ちは成立。疑った側は手札を1枚捨て、その後、自分の手番を通常どおり開始する。

## 14．試遊で確認する項目

本仕様のゲームバランスは未検証。特に以下を確認する。

- 初期配置の王が弱すぎず、守りを組み立てる余裕があるか。
- 手札3枚で、駒の選択と温存が十分に楽しめるか。
- 飛車・角を名乗る偽装打ちに偏りすぎないか。
- ダウト失敗時の「手札1枚を捨てる」が適切な重さか。
- 山の再構築が起こり、中終盤にもツモが続くか。
- 駒の本来の種類と盤上の種類を、無理なく管理できるか。
